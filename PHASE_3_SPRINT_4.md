### 2. PDF Report Generation

New ReportGenerator utility for creating professional PDF reports from portfolio data.

**Features:**
- Multi-page PDF with professional formatting
- Portfolio summary page with key metrics
- Detailed property analysis pages
- Charts and visualizations embedded in PDF
- Customizable report sections
- Footer with generation date and user info
- Watermark for draft/final status

**Report Structure:**
```
Page 1: Cover & Summary
├─ User Portfolio Summary
├─ Key Metrics (Total Value, YTD ROI, etc.)
├─ Executive Summary Section
└─ Report Metadata (Date, Generated By)

Page 2: Financial Overview
├─ ROI Trend Chart (as image)
├─ Asset Allocation Pie Chart (as image)
├─ Monthly Cash Flow Projection
└─ Annual Return Analysis

Page 3+: Property Details
├─ Individual Property Card per page
├─ Financial Metrics Table
├─ Valuation History
├─ Risk Assessment
└─ Investment Recommendation

Final Page: Appendix
├─ Methodology Notes
├─ Risk Definitions
├─ Model Confidence Intervals
└─ Disclaimer
```

**Implementation:**

```typescript
// src/frontend/src/utils/reportGenerator.ts
class ReportGenerator {
  constructor(portfolioData: PortfolioData);
  
  generatePDF(): Promise<void>;
  addCoverPage(): void;
  addSummaryPage(): void;
  addPropertyPages(): void;
  addAppendix(): void;
  downloadPDF(filename: string): void;
}

// Usage in component
const reportGen = new ReportGenerator(portfolioData);
const pdfBlob = await reportGen.generatePDF();
reportGen.downloadPDF(`portfolio_report_${date}.pdf`);
```

### 4. Custom Metrics & Dashboards

Enable users to create and track custom investment metrics.

**Features:**
- Create custom metrics from existing data fields
- Name, description, formula definition
- Metric types: Sum, Average, Ratio, Custom Formula
- Apply metrics across portfolio
- Custom dashboard widget support
- Save metric templates
- Share metric definitions

**Metric Formula Types:**

```typescript
interface CustomMetric {
  id: string;
  name: string; // "Debt-to-Equity Ratio"
  description: string;
  formula_type: "sum" | "average" | "ratio" | "formula";
  
  // For simple types
  field?: string; // field to sum/average
  
  // For ratio type
  numerator_field?: string;
  denominator_field?: string;
  
  // For custom formula
  formula?: string; // "total_value - total_debt"
  
  // Display options
  display_format: "percentage" | "currency" | "number";
  threshold_alert?: number;
}
```

**Example Custom Metrics:**
1. Cash-on-Cash Return: (Annual Cash Flow / Invested Capital) * 100
2. Debt Service Coverage Ratio: Annual Net Income / Annual Debt Payment
3. Equity Build Rate: (Annual Appreciation + Principal Paydown) / Total Value
4. Portfolio Stability Index: (Geographic Diversity Score + Asset Type Variety) / 2

## Architecture Decisions

1. **Recharts over Chart.js**: Composable React components, better TypeScript support, declarative API
2. **jsPDF over alternatives**: Lightweight, no server-side processing needed, good HTML support
3. **Client-side PDF generation**: No server load, immediate download, privacy-preserving
4. **Metric store in Zustand**: Consistent with existing state management, no additional dependencies
5. **Email scheduling API-ready**: UI complete, backend deferred for flexibility
